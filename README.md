# Task & Study Planner

A full-stack study planner web application built with React, TypeScript, and Firebase. Students can create, edit, complete, and delete study tasks, with priority levels, due dates, and real-time cloud sync.

## Features

- Create, read, update, and delete tasks (CRUD)
- Priority levels (High / Medium / Low) with color-coded visual indicators
- Smart due-date formatting (Due today, Due tomorrow, Overdue, etc.)
- Filter tasks by All / Today / Upcoming / Completed
- Live statistics (total, completed, pending)
- Mark tasks complete with toggle switches
- Undo accidental deletes via toast notification
- Light and dark mode with persisted preference
- Fully responsive (mobile, tablet, desktop)
- Cloud storage via Firebase Firestore

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite 8
- **Styling:** Bootstrap 5, custom CSS (warm cozy design system), Plus Jakarta Sans
- **Backend:** Firebase Firestore
- **Notifications:** react-hot-toast

## Prerequisites

- **Node.js** `^20.19.0` or `>=22.12.0`
- **npm** (comes bundled with Node)
- A **Firebase project** with Firestore enabled

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mintbanshee/React5-Group1.git
cd React5-Group1
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file in the project root with your Firebase credentials:

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

> **Note:** The `.env` file is excluded from version control. Never commit Firebase credentials to the repository.

### 4. Run the development server

```bash
npm run dev
```

The app will be available at [http://localhost:5173](http://localhost:5173).

## Firestore Schema

Tasks are stored in a single `tasks` collection. Each document has the following shape:

```ts
{
  id: string;            // auto-generated by Firestore
  title: string;
  subject: string;
  dueDate: string;       // ISO date string (YYYY-MM-DD)
  priority: "Low" | "Medium" | "High";
  imageUrl: string;
  isCompleted: boolean;
}
```
